The first super-rational like algorithm the authors consider is called **CliqueBot**, which is an algorithm that cooperates with any algorithm that has the exact same source code as it.<sup>[6](#footnote-6)</sup>

I.e., **CliqueBot** can be described by the following pseudocode.

```python
def CliqueBot(X: SourceCode) -> {Cooperate, Defect}:
    if X == source_code(CliqueBot):
        return Cooperate
    else:
        return Defect
```
